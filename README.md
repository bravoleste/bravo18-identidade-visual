# Bravo 18 — Identidade Visual

## Logo Oficial em Alta Resolução

Este repositório disponibiliza, para fins de **referência, preservação e consulta pública**, uma versão em alta resolução da identidade visual da **Bravo 18**, associada ao Fortaleza Esporte Clube, de Fortaleza, Ceará, Brasil.

O objetivo deste projeto é facilitar o acesso público a arquivos de boa qualidade da identidade visual, especialmente para pesquisas, referências gráficas e materiais digitais.

### Logo

A versão principal disponibilizada neste repositório está em alta resolução:

**3840 × 5431 pixels — PNG**

O arquivo preserva a proporção original da arte fornecida em formato PDF.

### Arquivos

* `logo-oficial-bravo-18-fortaleza-4k.png` — versão PNG em alta resolução
* `logo-oficial-bravo-18-fortaleza.png` — versão otimizada para uso digital
* `LOGO B18.pdf` — arquivo de referência original

### Sobre este projeto

Este é um **arquivo independente de referência** e não representa o site oficial ou um canal institucional da Bravo 18.

A página foi criada para contribuir com a preservação e a disponibilidade pública de uma versão em alta resolução da identidade visual da Bravo 18 na internet.
